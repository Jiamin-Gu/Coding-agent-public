# markdown.mjs：Markdown 子集渲染器

评论区要支持简单的 Markdown。实现 `markdown.mjs`，导出 `render(source)`：把 Markdown 文本转成 HTML 字符串。
用户输入不可信，**输出里不能出现用户能控制的 HTML 或可执行的链接**。

## 1. 转义

所有来自用户的文字（包括代码块、链接文字、链接地址）都要做 HTML 转义：

| 字符 | 转成 |
|---|---|
| `&` | `&amp;` |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `"` | `&quot;` |
| `'` | `&#39;` |

## 2. 块级元素

先把 `\r\n` 统一成 `\n`，再按行处理。输出的各个块之间用一个 `\n` 连接，没有其他空白。空输入（或只有空白）返回空字符串。

按优先级：

1. **代码块**：以 ```` ``` ```` 开头的行开始，到内容恰好是 ```` ``` ````（去掉首尾空白后）的行结束。
   中间的行原样保留（只做转义），用 `\n` 连接：`<pre><code>内容</code></pre>`。
   开头一行 ```` ``` ```` 后面可以写语言名，如 ```` ```js ````；语言名只由字母、数字、`_`、`+`、`-` 组成时输出
   `<pre><code class="language-js">`，否则忽略语言名。没有结束行的代码块一直延续到文本末尾。代码块里不做行内格式。
2. **标题**：`#`、`##`、`###` 加一个空格开头的行 → `<h1>`、`<h2>`、`<h3>`，内容是 `#` 和空格之后的文字（去掉首尾空白，做行内格式）。
   四个及以上 `#`、或 `#` 后面没有空格的，按普通段落处理。
3. **列表**：连续的以 `- ` 开头的行组成一个列表：`<ul><li>…</li><li>…</li></ul>`，每项是 `- ` 之后的文字（去掉首尾空白，做行内格式）。
4. **空行**（只有空白的行）：分隔段落，本身不输出。
5. **段落**：其他连续的行组成一个段落，各行去掉首尾空白后用一个空格连接：`<p>…</p>`（做行内格式）。
   遇到代码块、标题、列表的开始行时，当前段落结束。

## 3. 行内格式

在一段文字里依次处理：

1. **行内代码**：一对反引号之间的内容 `` `…` `` → `<code>…</code>`，内容只转义、不再做其他格式。没有配对的反引号按普通字符。
2. 其余文字先转义，再处理：
   - **链接** `[文字](地址)`：地址不含空白和 `)`。地址去掉首尾空白后，以 `http://`、`https://`、`mailto:` 开头（不区分大小写）才输出
     `<a href="地址">文字</a>`；其他地址（比如 `javascript:`、`data:`、相对路径）只输出文字，不生成链接。
     文字部分可以有加粗、斜体。
   - **加粗** `**文字**` → `<strong>文字</strong>`
   - **斜体** `*文字*` → `<em>文字</em>`（在加粗之后处理）

   加粗、斜体都是非贪婪匹配，里面至少有一个字符；没有配对的星号按普通字符。

## 4. 示例

```
# 标题

第一行
第二行 **加粗** 和 `a<b`

- 一项 [官网](https://example.com)
- 二项 [点我](javascript:alert)
```

渲染为：

```
<h1>标题</h1>
<p>第一行 第二行 <strong>加粗</strong> 和 <code>a&lt;b</code></p>
<ul><li>一项 <a href="https://example.com">官网</a></li><li>二项 点我</li></ul>
```
