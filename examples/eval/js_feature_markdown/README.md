## 改动内容

**`markdown.mjs`** — 实现 `render(source)`：

- **转义**：`escapeHtml` 统一处理 `& < > " '`（`&` 先处理，避免二次转义）。
- **块级解析**（按优先级，块之间用单个 `\n` 连接）：
  1. 代码块：以 ``` 开头的行开始，到去掉首尾空白后恰为 ``` 的行结束；无结束行则延伸至末尾。语言名只含 `[\w+-]` 才输出 `class="language-…"`，否则忽略。块内只转义、不解析行内格式。
  2. 标题：`^(#{1,3}) `，其余（4 个以上 `#` 或无空格）按段落。
  3. 列表：连续 `- ` 行合成 `<ul>`。
  4. 空行只分隔。
  5. 段落：连续行去首尾空白后用单空格连接；遇到代码块/标题/列表/空行即结束。
- **行内格式**：先切出行内代码（内容仅转义），其余部分先转义，再按「链接 → 加粗 → 斜体」处理。链接地址裁剪后仅 `http://`、`https://`、`mailto:`（不区分大小写）才生成 `<a>`，其他（`javascript:`、`data:`、相对路径等）只输出文字；链接文字支持加粗/斜体。加粗、斜体非贪婪且至少一个字符。
- **安全**：所有用户文字（含链接文字、链接地址、代码）均转义，且链接地址校验在转义之后进行，因此无法注入属性或可执行链接。
